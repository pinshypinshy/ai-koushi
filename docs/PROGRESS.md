## 実測

講義作成の実測（2026-08-30、教材18,398文字）：**約198秒・$0.31**。内訳は①骨子生成が49.7秒で
8ステップ、②確認テスト生成が148.2秒で16問。②の入力12,253トークンのうち11,332トークン（92%）が
コンテキストキャッシュから読まれており、§8.2 が実装必須とした部分は効いている。
作成コストの約9割が出力トークンで、その65%が思考トークンだった（§8.2.2）。

確認テスト生成だけが失敗した場合の分岐（§4.1.6）は、意図的に失敗させないと通らないため未検証。

本番での講義作成の実測（2026-09-01）：**約126秒・$0.20**。①骨子生成が29.8秒、
②確認テスト生成が96.5秒で15問。②の入力8,074トークンのうち7,646トークン（95%）が
コンテキストキャッシュから読まれている。ローカルの実測（198秒・$0.31、教材の分量は異なる）
と比べて遅くなる要素は無く、Workers 上でも同じ経路が成立している。

受講の実測（2026-09-01、同じ講義）：③講義本文の生成が6.1秒で出力772トークン、$0.0039。
入力11,724トークンのうち11,555トークンがコンテキストキャッシュから読まれている。
⑤ステップ要約は2.0秒・$0.0009。1発話あたりの費用は1円に満たない。

**初回トークンの到達は4.1秒で、§8.1 の目標（3秒以内）を超えている。** 文字は約1.9秒かけて
少しずつ届いており、ストリーミング自体は経路上も動作している（Vite の proxy 経由でも
チャンクの間隔が保たれることを確認済み）。受講時の体感としては許容範囲だが、目標は未達である。
